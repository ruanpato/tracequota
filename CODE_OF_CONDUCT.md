# Code of conduct

We want an inclusive, respectful developer community. Be considerate, discuss ideas rather than attacking people, and respect privacy. Harassment, discrimination, threats, sexualized conduct, doxxing and sustained disruption are unacceptable.

Maintainers may remove harmful content, reject contributions or restrict participation when necessary, with proportionate and consistent enforcement. Report concerns privately to the repository owner through a verified contact channel. Do not post private information in public issues. This policy applies in project spaces and when representing the project publicly.
