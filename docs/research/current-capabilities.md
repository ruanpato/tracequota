# Current capabilities — researched 2026-09-28

Sources are upstream documentation; documentation support is distinct from a tested Claude installation.

## Claude monitoring
[Official monitoring reference](https://code.claude.com/docs/en/monitoring-usage) documents OTLP metrics and events. Enable `CLAUDE_CODE_ENABLE_TELEMETRY`, `OTEL_METRICS_EXPORTER`, `OTEL_LOGS_EXPORTER`, protocol and endpoint. HTTP/protobuf works on port 4318. API request events carry session/prompt/request identifiers, model, duration, separate input/output/cache-read/cache-creation counts and provider-calculated cost. Metric token types include input, output, cacheRead and cacheCreation. Repository attributes require opt-in. Traces are beta: `CLAUDE_CODE_ENHANCED_TELEMETRY_BETA=1` plus `OTEL_TRACES_EXPORTER=otlp`. Interaction roots parent LLM/tool spans; agent identifiers permit attribution. TraceQuota retains provider-specific metadata through a strict allowlist. Logs and spans are deduplicated by request ID. Counters are stored separately and never added to request totals. Provider cost here is an emitted estimate, not subscription billing. Older runtimes can omit fields.

## Quota
[Official status-line schema](https://code.claude.com/docs/en/statusline) documents `rate_limits.five_hour` and `rate_limits.seven_day`, each with `used_percentage` and epoch `resets_at`. Available after the first API response for eligible Pro/Max sessions, requiring v2.1.251 or later. TraceQuota's optional stdin adapter forwards only these fields, session ID and timestamp to localhost. It makes no Anthropic call, reads no credentials and introduces no polling. Missing payloads remain missing. Manual snapshots work independently. Estimates require explicit user-supplied capacity; they cannot infer subscription quota from tokens. The experimental provider is a disabled interface, with no scraping implementation. API rate-limit headers are API limits, not equivalent subscription windows.

## Lifecycle
[Official hooks](https://code.claude.com/docs/en/hooks) exposes session, turn, tool and subagent lifecycle events. HTTP hooks send JSON to local endpoints without a native companion. TraceQuota's example captures SessionStart/SessionEnd metadata only; prompt/body/transcript fields are discarded. UserPromptSubmit/Stop are turns, and task-list hooks are not a universal feature-task primitive. V1 uses prompt.id or trace ID for interactions, explicit tracequota.task.id for manual tasks, otherwise a labeled session-activity bucket. Hooks can fail or be missed; running state is not proof the agent is currently active.

## Desktop
[Official Desktop guide](https://code.claude.com/docs/en/desktop) describes Local environment settings in the environment dropdown's gear editor. Shell exports are not consistently inherited. Put telemetry variables in that editor or user settings and start a new Local session. Desktop Code Local is documentation-supported but not live-provider validated in this repository. Chat, Cowork, Cloud and remote SSH are not automatically supported by a localhost collector.

## Backend services
[Phoenix Docker](https://arize.com/docs/phoenix/self-hosting/deployment-options/docker) documents port 6006 for UI and HTTP traces, 4317 for internal gRPC and persistent SQLite or PostgreSQL. V1 uses a named SQLite volume for Phoenix, PostgreSQL for the ledger. [Collector configuration](https://opentelemetry.io/docs/collector/configuration/) defines receivers, processors, exporters and separate signal pipelines. V1 exports sanitized traces to Phoenix/API, logs to API and metrics to Prometheus/API; delta counters are converted before Prometheus. [Prometheus configuration](https://prometheus.io/docs/prometheus/latest/configuration/configuration/) supplies scrape targets. [Grafana provisioning](https://grafana.com/docs/grafana/latest/administration/provisioning/) supports repository-owned datasources and dashboards. Provision PostgreSQL with a read-only role and Prometheus without manual UI setup.

## Pricing
[Anthropic pricing](https://platform.claude.com/docs/en/about-claude/pricing) supplies USD token rates for the bundled catalog verified 2026-09-28, including Sonnet 4.6/5.5, Opus 4.6/5.5 and Haiku 4.5. Cache writes require a known five-minute or one-hour TTL when positive; missing TTL leaves that component partial. Unsupported Anthropic tiers/platforms/regions remain unpriced. The versioned registry also includes selected OpenAI and Google models with explicit tier/context rules. See [registry coverage](../../pricing/README.md) for current catalogs. Unknown models return null rather than zero; historical estimates remain frozen.
